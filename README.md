## What lives here

| Path | What it is |

## Using the brand

The Host39 colors at a glance.

| Swatch | Name | Hex | Use |
|---|---|---|---|
| ![Ink](https://img.shields.io/badge/-%20%20%20%20%20-23303A?style=flat-square) | Ink | `#23303A` | Logo, headings, body text |
| ![Paper](https://img.shields.io/badge/-%20%20%20%20%20-F7F5F0?style=flat-square) | Paper | `#F7F5F0` | Background |
| ![Ember](https://img.shields.io/badge/-%20%20%20%20%20-E07A5F?style=flat-square) | Ember | `#E07A5F` | Accents, the power dot |
| ![Ember Text](https://img.shields.io/badge/-%20%20%20%20%20-B4573A?style=flat-square) | Ember Text | `#B4573A` | Ember for words on light backgrounds |
| ![Sage](https://img.shields.io/badge/-%20%20%20%20%20-6FA287?style=flat-square) | Sage | `#6FA287` | Status, success |
| ![Mist](https://img.shields.io/badge/-%20%20%20%20%20-DCE3E8?style=flat-square) | Mist | `#DCE3E8` | Fills, dividers |

Fonts are **Outfit** for headings and **Inter** for body text, both free on Google Fonts.

Contributing to a Host39 project? You are welcome to use these assets there. For anything else, read the [brand policy](TRADEMARKS.md) first.
